# 0.3.1 修复与验收边界

本轮完成源码修复、合成回归、公开构建和本地 Git 留档。**尚未完成用户现有 Chrome 上的发送前实机验收；未做真实发送测试；没有宣称已达到平台稳定发送验收标准。**

## 修复

- 任务按创建时间领取，避免 UUID 字典序改变操作顺序；无期限、布尔期限和非有限期限不派发。
- HTTP 结果拒绝错误长度、非对象 JSON、错误 ID、非有限 JSON 数值；畸形输入返回 JSON 错误，不中断后续服务。
- 开聊窗口已绑定时，职位控件读取失败仍可续接同一窗口；目标改变、手动切换和过期继续拒绝。
- 最终点击后与续接核验时重新确认账号、原候选人行和原生目标绑定；行被替换保留未知。
- verified 必须为布尔 true 且有非空回执；互相矛盾的成功/未提交标记不能计成功。
- 新增 preflight 只读最终回读，以及服务端 --read-only 模式；只读服务拒绝 run 且不消费许可。
- 审核证据、回传结果和台账改为项目内 .runtime；旧台账复制工具校验格式、哈希、冲突及源文件不变。
- 生产账号、岗位与问候移入 Git 忽略的本机配置；日志、个人记录和运行数据不进入公开仓库。新增发布隐私检查脚本。
- 页面协议升级到 6，避免旧内容脚本与新控制器混用。

## 本轮验证

Node 113 项、Python 48 项通过，共 161 项；结果见 [test-results.json](test-results.json)。涵盖生产 content.js 的合成 DOM、控制器、一次许可、本机 HTTP、持久化台账、故障恢复、跨进程锁和跨日计数。新增 Python 测试跑通审核许可到 HTTP 消费、模拟回执及 finish 落盘的完整链；它没有真实浏览器或平台发送。

`node tools/synthetic-flow.mjs` 另外输出 9 步合成执行轨迹：准备、最终回读、模拟单次提交、回执、重复阻断、停止阻断、点击后身份丢失。逐步数据在私有 `.runtime/test-results/synthetic-flow.json`。此日志与独立离线 demo 都不能作为实机截图。

本轮没有创建新浏览器 profile。已有 Chrome 未提供可附着的调试连接；浏览器访问 host 不可用；原生 Computer Use 因无法可靠确认当前浏览器 URL 而停止本轮 UI 操作。不能据此判断猎聘登录是否仍有效，也没有继续绕过工具限制。真实页面未完成准备，截图/录屏缺失。旧 [browser-smoke.json](browser-smoke.json)、[public-package-test.json](public-package-test.json) 和旧验收报告是历史资料，不代表本轮浏览器验证。

当前本机服务以只读模式启动，扩展心跳未连接。未创建新的生产发送许可、未执行生产 run、未向任何真实候选人发送招呼；后台持续运行和真实默认文案适配仍待平台验收。
