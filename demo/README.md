# 离线交互演示

本目录是 猎聘招聘助手的**交互说明夹具**。全部候选人、公司、职位、联系记录均为虚构数据；不连接猎聘，不会发送真实消息，未接入 AI 服务。

## 打开

直接双击 `index.html` 即可。无构建、无依赖、无账户或令牌。浏览器允许本地存储时，刷新可保留本页的虚构演示进度；存储不可用时仍能操作，但刷新不保留。

也可在项目目录运行：

```powershell
python demo/serve.py
```

然后打开 `http://127.0.0.1:18764/`。仅使用该 `demo` 目录作为静态服务根目录；不要将工作区或真实资料目录作为服务器根目录。

## 三分钟演示路线

1. 打开候选人 A 的详情，观察学历、工作履历和项目证据，点击“载入预置审核结果”。
2. 点击“准备模拟打招呼”，核对演示职位和默认文案，确认模拟发送。
3. 观察“继续沟通”与已确认次数，关闭模拟相似人选窗口。再次选择此人，看到去重状态。
4. 查看 C 和 F：分别展示证据不足与教育门槛不符。它们不会进入发送队列。
5. 切换“模拟回执丢失”，对另一位通过样本执行一次模拟发送：它进入“结果不明”，确认数不增加，后续发送被阻断。点击“核验未明回执”，确认恢复原记录而不重复发送。
6. 点击“演示断线”再恢复连接，或者刷新页面，观察虚构进度保留。
7. 点击“载入第 10 条边界场景”：明确预置 9 条虚构成功记录；再完成一条后，下一次准备会要求换关键词。选择另一个词并提交后继续。
8. 选择“模拟安全验证”：操作停止。结束该故障场景只是关闭本地模拟，不是解决或绕过真实验证码。

支持普通列表翻页、预置关键词切换、错选职位阻断、停止/恢复、重置演示。仅更改下拉框而不点击搜索不会修改已应用的关键词和列表。

## 与生产实现的区别

- `model.js` 是便于讲解的确定性演示状态模型，不是生产扩展的第二套发送实现。
- “审核”加载固定演示结果，不分析真实简历，不代表内置 AI。
- 模拟回执由本地变量生成，不等于真实平台回执。
- 模拟断线只切换演示状态，不连接本机桥接服务。
- 页面以 CSP `connect-src 'none'` 限制网络连接；没有 `fetch`、WebSocket、账号或密钥。
- 本目录不读取生产扩展存储、真实候选人快照、许可或联系台账。
- 演示测试通过只能证明本夹具的状态流程，不能证明生产网页适配、成功率或平台稳定性。

## 设计与文件

白底工作台，深蓝主色 `#185ca1`，正文 `#173149`，辅助信息 `#526779`，分隔线 `#d5e0e9`，成功 `#247348`、风险 `#a63237`。系统字体 Segoe UI / Microsoft YaHei UI，无远程字体。左侧列表、右侧证据、下方事件记录，让招聘操作与工程约束在同一视图中对应。窄屏改为纵向布局，按钮支持键盘，状态消息支持读屏。

- `index.html`：页面结构与禁止网络连接的 CSP。
- `style.css`：响应式样式。
- `model.js`：虚构样本及可测试状态转换。
- `app.js`：交互和演示状态本地保存。
- `serve.py`：可选静态服务，固定只公开本目录，监听本机 `127.0.0.1`。

从项目目录运行离线模型测试：

```powershell
node --test test/demo-model.test.mjs
```
