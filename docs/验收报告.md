## 复现

```powershell
python tools/verify.py
node tools/browser-smoke.mjs
python build.py
```

第二条需先安装或指定 Playwright 模块、设置 SMOKE_CHROME；见 README。Windows受限沙箱可能阻止临时目录清理和随机本机端口，测试需在允许这些操作的隔离环境运行。发生环境错误应保留日志，不能算通过。
